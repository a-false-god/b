Schema (tools/migrate_002.sql)
CREATE TABLE ratings (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  scope TEXT NOT NULL CHECK (scope IN ('user_global','user_axisB','question')),
  owner_id INTEGER,          -- user_id for user_* scopes, NULL for question
  axis_value TEXT,           -- axis-B domain for user_axisB, NULL otherwise
  question_id INTEGER,       -- set when scope='question'
  rating REAL NOT NULL DEFAULT 1500.0,
  games INTEGER NOT NULL DEFAULT 0,
  updated_at TEXT NOT NULL DEFAULT (datetime('now')),
  UNIQUE (scope, owner_id, axis_value, question_id)
);

CREATE TABLE rating_history (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL REFERENCES users(id),
  rating REAL NOT NULL,
  created_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX idx_rating_history_user ON rating_history(user_id, created_at);
Algorithm — run transactionally inside POST /api/answers
Compute is_correct, insert the answer_events row (existing behavior).
In the SAME transaction, update three ratings (fetch or initialize at ELO_INIT):
user_global for this user
user_axisB for this user on the question's axis-B domain (from question_classification)
question for this question (global, across users)
Math (S = 1 correct / 0 wrong; K_eff = ELO_K × question.points / 2):
E  = 1 / (1 + 10 ** ((R_question - R_user) / 400))
R_user'     = R_user     + K_eff * (S - E)
R_question' = R_question - K_eff * (S - E)
Apply the same S/E to the user_axisB rating.
Upsert all three ratings rows (games += 1), then insert one rating_history snapshot with the new user_global rating.
Commit once. No answer may exist without its rating update.
Endpoints
GET /api/dashboard/summary → { user_rating, per_axis_b: {domain: rating}, events_total, events_today, coverage: {never_seen, seen, mastered}, repeats_due }
GET /api/dashboard/rating_history?days=30 → chronological [{created_at, rating}] for the sparkline.
repeats_due (interim rule until HLR): distinct questions whose latest event is wrong OR hesitant (is_correct=1 AND time_ms > HESITATION_THRESHOLD_MS) within the last REVIEW_WINDOW_DAYS days.
